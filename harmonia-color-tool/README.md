# Harmonia – Il tuo colore è la tua firma

Tool di analisi armocromica AI. Carica una foto del tuo viso e scopri stagione armocromica, palette ideale e consigli di stile.

## Come iniziare

1. Ottieni una API key su [console.anthropic.com](https://console.anthropic.com)
2. Apri `index.html` nel browser (o deploya su Netlify/GitHub Pages)
3. Inserisci la API key nel modale iniziale
4. Carica una foto e analizza!

## Deploy locale

```bash
# Apri direttamente nel browser
open index.html

# Oppure con server locale
npx serve .
```

## Deploy Netlify

Trascina la cartella su [app.netlify.com](https://app.netlify.com) — online in 30 secondi.

## Deploy GitHub Pages

In Settings → Pages → Source: main → / (root)
URL: `https://TUO_USERNAME.github.io/harmonia-color-tool/`

## Privacy

La API key è salvata solo in `localStorage` del tuo browser. Nessun server intermedio.
